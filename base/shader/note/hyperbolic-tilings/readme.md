# Hyperbolic Tilings

https://www.shadertoy.com/view/4sf3zX

This GLSL shader implements **triangular Coxeter group tessellations** (also called **triangle group tilings**) using a generalized framework that works in **spherical, Euclidean, or hyperbolic space**, depending on the parameters `p`, `q`, and `r`.

It uses **reflections in triangle edges**, projected via **stereographic projection**, to create beautiful, mathematically rich **geometric tilings**, especially **hyperbolic tilings in the Poincaré disk**. Let’s break down how it all works.

### What Is a Triangle Group?

A **triangle group** is generated by **reflections in the sides of a triangle** where the angles are:

* π/p between edge a and b,
* π/q between edge b and c,
* π/r between edge c and a.

Depending on the sum of `1/p + 1/q + 1/r`, the tessellation lives in:

| Space Type | Condition             | Geometry Used               |
| ---------- | --------------------- | --------------------------- |
| Spherical  | `1/p + 1/q + 1/r > 1` | Sphere                      |
| Euclidean  | `1/p + 1/q + 1/r = 1` | Plane (e.g., triangle grid) |
| Hyperbolic | `1/p + 1/q + 1/r < 1` | Hyperbolic disk             |

This shader supports all three geometries via a general model and **space-type dependent dot product**.

### Key Concepts Used in the Shader

| Concept                      | Meaning and Use                                                      |
| ---------------------------- | -------------------------------------------------------------------- |
| **Coxeter groups**           | Groups generated by reflections across triangle sides.               |
| **Fold function**            | Repeatedly reflects a point until it lands inside the base triangle. |
| **Hyperbolic metric**        | Uses special dot products (`hdott`, `hdots`) for curved geometry.    |
| **Stereographic projection** | Embeds 2D plane into 3D projective space for tessellation.           |
| **Poincaré disk model**      | The 2D rendering for hyperbolic tiling (unit disk projection).       |

### Step-by-Step Explanation

#### 1. Parameters: Triangle Angles

```glsl
const int pParam = 3;
const int qParam = 3;
const int rParam = 4;
```

These set the triangle's internal angles to:

* π/3 between sides a and b
* π/3 between b and c
* π/4 between c and a

So the sum is:
`1/3 + 1/3 + 1/4 = 1.0` → **Euclidean space**

If you used `p=3, q=3, r=5`, the sum is `< 1`, giving **hyperbolic space**.

#### 2. Space Type Detection

```glsl
spaceType = sign(q*r + p*r + p*q - p*q*r);
```

* This tests whether `1/p + 1/q + 1/r` is greater than, equal to, or less than 1.
* The sign determines the geometry:

  * `+1` = spherical
  * ` 0` = Euclidean
  * `–1` = hyperbolic

#### 3. Geometry Setup: Reflection Planes and Triangle

```glsl
nb, nc = triangle edge normals
pA, pB, pC = triangle corners in hyperbolic model
q = U*pA + V*pB + W*pC
p = normalized q
```

This computes the **barycentric combination** of triangle vertices to get a point `p`, which will be reflected repeatedly.

The key math here uses **hyperbolic-style dot products** (`hdott`, `hdots`) and **normalization** with respect to that geometry.

#### 4. Fold: Reflecting into the Triangle Domain

```glsl
vec3 fold(vec3 pos)
```

This function **reflects a point** across triangle edges until it ends up in the "fundamental domain" — the base triangle.

This is what generates the **tessellation**. Every reflected copy tiles the plane just like a mirror maze.

#### 5. Distance to Segment: For Anti-Aliasing

```glsl
float dist2Segment(...)
```

This function computes the **projected distance** from a point to each of the triangle’s three sides, taking into account the space’s geometry.

It is used to **soften the rendering** of the triangle edges (with `smoothstep`) to prevent aliasing and jaggedness.

#### 6. Main Color Function

```glsl
vec3 color(vec2 pos)
```

* Converts screen space to Poincaré disk coordinates.
* Projects point into hyperbolic 3D (`vec3(2*pos, 1 - spaceType*r²) / (1 + spaceType*r²)`).
* Reflects the point via `fold(...)`.
* Computes distance to triangle edges.
* Blends between **line color** and **background color** depending on distance.

If the space is hyperbolic, it also fades toward the edge of the Poincaré disk (r = 1) for smoother borders.

#### 7. Animation of Triangle Weights

```glsl
void animUVW(float t)
```

Animates the `U, V, W` values used to compute `q = U*pA + V*pB + W*pC`, which subtly shifts the center of the projection and warps the patterns over time.

#### 8. Rendering the Final Image

```glsl
void mainImage(...)
```

* Converts fragment coordinates to centered `uv` space.
* Sets `aaScale` (half-pixel size) for smoothing.
* Calls `init()` to set up geometry.
* Calls `color(uv)` and outputs final color.

### Summary of Techniques

| Feature                  | Method                                            |
| ------------------------ | ------------------------------------------------- |
| Triangle Group Tilings   | Coxeter reflections (p-q-r triangle groups)       |
| Stereographic Projection | Embeds triangle geometry into 3D projective space |
| Hyperbolic Geometry      | Dot products adapted to space curvature           |
| Tiling                   | Reflection across triangle edges in fold()        |
| Anti-Aliasing            | Segment distance smoothing                        |
| Animation                | Varying barycentric weights (U, V, W)             |

### How to Explore and Modify

Try changing the values of `pParam`, `qParam`, and `rParam`:

* `p=3, q=3, r=3` → Spherical (tiling on the sphere)
* `p=3, q=3, r=6` → Euclidean (regular triangle grid)
* `p=3, q=3, r=7` → Hyperbolic (classic hyperbolic tiling)

Other ideas:

* Increase `Iterations` for sharper boundaries
* Change `segColor` to color the lines
* Use Mobius transforms inside `color()` to shift/rotate the entire pattern
